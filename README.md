Neon Hours is an offline poster studio for turning local photos and your own headline into a Vice City-inspired, three-panel neon-noir cover. Assign a different image to each frame, fine-tune its crop, then export a square, portrait, or landscape PNG. Your photos never leave your device.

## Run it

```sh
node serve.ts
```
